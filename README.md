# 沈计指南

面向中国科学院沈阳计算技术研究所考生的公益信息站。把分散的招生目录、复试规则、录取数据和往届经验整理成可以直接在网页中阅读、检索与核对的报考指南。

> 非官方网站。内容仅供参考，招生政策、专业目录与名额请以研究所当年发布的官方通知为准。

## 在线访问

- GitHub Pages：<https://huazhao-nine.github.io/sict-web/>
- 2027 中科院沈计所考研交流群：网站右上角“加入群聊”

## 网站内容

| 栏目 | 内容 |
| --- | --- |
| 报考指南 | 招生专业、初试科目、复试流程、培养与生活信息 |
| 历年数据 | 2024—2026 年录取数据及 2026 年完整数据报告 |
| 经验归档 | 24 篇复习、初试与复试经验，全部转为站内文章 |

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 <http://localhost:3000/>。

## 构建与验证

```bash
# 常规生产构建
npm run build

# 完整测试
npm test

# 生成适配 GitHub Pages /sict-web 子路径的静态站点
npm run pages:build
```

GitHub Pages 静态文件生成在 `dist/client`，构建脚本会补齐 `/sict-web` 子路径和无扩展名路由。推送到 `main` 后，仓库中的 GitHub Actions 工作流会自动构建并发布。

## 数据口径

- 数据来自本项目 `docs` 中的学生整理报告、录取统计表和报考指南；该本地资料目录不随源码公开提交。
- `scripts/import-experiences.mjs` 会将 `docs/经验分享` 中的 24 份唯一资料转为站内文章数据，并排除重复文件。
- 公开页面只提供网页阅读，不提供 PDF、Word、Excel 等原始材料下载。
- 数据缺失、统计误差与政策变化均会明确保留边界；使用前请阅读站内[免责声明](https://huazhao-nine.github.io/sict-web/disclaimer/)。
